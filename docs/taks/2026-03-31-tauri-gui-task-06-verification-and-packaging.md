# 任务 06：验证、联调与 macOS 打包

## 目标

为共享层、CLI、Tauri command 和 GUI 提供可重复执行的验证方案，并完成 macOS 首版打包闭环。

## 背景

桌面壳和页面完成后，如果没有验证矩阵和打包说明，项目仍无法稳定交付或复现。

## 任务范围

- 补齐 Rust 单元测试
- 补齐关键前端交互测试
- 完成 Tauri dev/build 冒烟
- 形成 `desktop` 本地开发说明
- 形成 macOS 打包说明

## 不在范围内

- Windows 打包
- 自动更新
- CI/CD 发布流水线

## 验证矩阵

### Rust 共享层

- 配置缺失
- 配置解析失败
- 门店数量不足
- OpenID 数量不足
- 指定门店未命中
- 汇总统计正确

### CLI

- 帮助命令
- 正常执行
- 参数错误

### GUI / Tauri

- 启动读取运行时状态
- 正常执行
- 部分失败展示
- 整体失败展示
- 配置目录初始化

## 交付物

- Rust 测试代码
- 前端测试代码
- 开发与打包文档
- macOS 构建结果验证记录

## 验收标准

- `cargo test` 通过
- `cargo clippy --all-targets --all-features -- -D warnings` 通过
- 前端测试通过
- `desktop` 开发模式可运行
- macOS 构建可产出应用包
- 打包应用可读取运行时配置目录

## 依赖关系

- 依赖任务 01 到 05 全部完成
