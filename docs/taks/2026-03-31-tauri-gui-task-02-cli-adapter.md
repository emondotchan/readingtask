# 任务 02：CLI 入口适配到共享应用层

## 目标

在不改变现有 CLI 使用方式的前提下，让 CLI 只负责命令解析和结果渲染，业务执行完全走共享 library。

## 背景

任务 01 完成后，CLI 不应再保留独立的业务流程副本，否则 GUI 接入后会产生双实现分叉。

## 任务范围

- `src/main.rs` 保持精简入口
- `src/cli.rs` 继续负责参数解析
- CLI 将参数转换为 `TaskRunRequest`
- CLI 调用共享 `run_task`
- CLI 将 `TaskRunSummary` 渲染为当前文本输出风格

## 不在范围内

- 新增 CLI 参数
- 调整 CLI 用户输入方式
- Tauri 或 React 相关代码

## 关键实现要求

- 原有参数名保持不变
- `shopcodes` 仍支持逗号分隔输入
- 错误提示必须保持中文、可操作
- 逐条结果输出要保留，不能退化成只输出最终摘要

## 交付物

- CLI 与共享层的转换逻辑
- CLI 专用输出渲染逻辑

## 验收标准

- `cargo run -- --help` 仍可正常显示参数
- 现有常用命令组合仍能运行
- 文本输出包含逐条结果和最终状态

## 依赖关系

- 依赖任务 01 完成
- 与任务 03 可并行
