# 任务 05：GUI 主工作台实现

## 目标

实现首版可用的单页 GUI，覆盖参数输入、执行状态、进度展示和结果明细展示。

## 背景

桌面壳和 command 打通后，用户仍需要一个完整的工作台来替代 CLI 输入和终端输出。

## 任务范围

- 实现单页工作台布局
- 展示运行时配置目录和配置健康状态
- 实现输入表单
- 实现表单校验
- 实现执行中状态
- 实现结果汇总和明细列表
- 监听并展示运行进度事件

## 不在范围内

- 多页面导航
- 历史记录
- 参数模板
- 取消执行
- 配置文件编辑器

## 页面最小结构

- 顶部标题区
- 配置状态卡片
- 参数表单卡片
- 执行状态与结果卡片

## 关键实现要求

- 表单字段与 CLI 保持一致
- `count` 默认值为 `1`
- `shopcodes` 支持逗号和换行分隔
- 提交时按钮进入禁用态
- 运行中显示当前进度
- 结果页既展示摘要，也展示逐条结果
- 错误信息必须清楚区分“输入错误”“配置错误”“执行错误”

## 交付物

- React 页面
- 基础组件
- 前端 API 层
- 前端状态管理逻辑

## 验收标准

- 用户无需命令行即可完成一次任务执行
- 配置未就绪时，界面可明确告知问题
- 执行完成后可查看成功数、失败数和每条结果
- 运行中列表能增量更新

## 依赖关系

- 依赖任务 03 和任务 04
- 完成后可进入整体联调
